# Build specification

Implement a reproducible Python/PyTorch research project that reads RayVerse
D2Los multipath records, produces physically defined 8x8-to-1x1 64-subcarrier
CSI, trains a conditional multipath VAE, applies explicit power/delay/K/LoS
constraints, and evaluates condition accuracy, distribution fidelity and
diversity without modifying the sibling PGC-VAE repository.
